# 诡秘之主 · GvG 战术板

《诡秘之主》GvG 战术板是一个纯前端的离线沙盘工具，用于赛前摆阵、绘制推进路线和按阶段推演。双击 `index.html` 即可在浏览器中运行，无需安装、无需启动服务器。全部资源本地加载，零外链、零依赖，工程与设置保存在浏览器本地。
